# AI Tools

Welcome to the AI Tools module! This folder contains all the assignments and exercises designed to introduce you to various AI tools and how they can be leveraged in modern web design and development workflows.

## Module Structure

We are breaking down AI concepts and tools into manageable, hands-on sessions. Each session has its own folder containing a dedicated `README.md` file explaining the tasks, resources, and expected outcomes.

### 📚 Sessions

- **[Session 1: The Role of AI in Modern Web Design](./Session_01)**
- **[Session 2: Using ChatGPT & GitHub Copilot for Coding](./Session_02)**
- **[Session 3: Figma AI and Uizard for Design Automation](./Session_03)**
- **[Session 4: AI Image & Asset Generation](./Session_04)**
- **[Session 5: SEO & Content with AI](./Session_05)**
- **[Session 6: Mini Project: AI-Generated Landing Page](./Session_06)**

## Getting Started

1. Make sure you are in the `AI Tools` directory.
2. Navigate to the session folder you want to work on (e.g., `cd Session_01`).
3. Read the `README.md` file inside that specific session folder to understand the requirements and objectives.
