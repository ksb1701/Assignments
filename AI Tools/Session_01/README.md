## Task 2: Figma AI & Uizard vs. Traditional Tools

| Feature | AI Tools (Figma AI, Uizard) | Traditional Tools (Photoshop, Basic Sketch) |
| :--- | :--- | :--- |
| **Speed from Idea to Draft** | Instant generation from text prompts or rough sketches. | Requires manual placement of every single element. |
| **Asset Generation** | Can automatically generate placeholders, icons, and even copy text. | Designer must source or create all assets manually. |
| **Design Variations** | Easily generates multiple layout variations in seconds. | Variations must be painstakingly rebuilt or duplicated/modified. |
| **Component Recognition** | (Uizard) Converts hand-drawn wireframes into digital UI components. | Wireframes must be traced or recreated digitally from scratch. |
| **Learning Curve** | Lower barrier to entry; prompt-driven workflows are intuitive. | Steeper learning curve for mastering precise manual tools. |

## Task 3: AI for Front-End Development (Zomato-style site)

| How AI Speeds Up Development | Ethical Risk |
| :--- | :--- |
| **1. Generating Boilerplate Code:** AI can instantly write the basic HTML/CSS skeleton for complex components like a restaurant review card. | **Code Plagiarism/Copyright:** The AI might regurgitate licensed code snippets it was trained on without proper attribution. |
| **2. Writing Helper Functions:** AI can quickly write logic for things like calculating average star ratings or formatting timestamps on reviews. | **Over-reliance & Skill Atrophy:** Developers might blindly trust the AI's logic without understanding it, leading to unmaintainable code. |
| **3. CSS Styling & Responsiveness:** AI can generate the CSS Grid/Flexbox code needed to make the restaurant grid look good on mobile and desktop. | **Accessibility Neglect:** AI-generated CSS might look good visually but lack proper ARIA labels or contrast ratios, excluding users with disabilities. |
