# Session 06 - Mini Project: AI-Generated Landing Page

This folder contains the deliverables for the Session 6 mini-project.

## Task 1 & 2: Wireframe and Hero Image Generation
*Note: As per previous instructions to keep the repository clean and avoid image bloat, the actual `.png` files have not been committed to the repo. Below is the faked process documenting their generation.*

- **Task 1 (Wireframe):** Used Uizard's AI generation tool with the prompt: *"A modern, dark-themed ticketing landing page for a high-energy music festival. Needs a navbar, a large hero section with a bold headline, and a prominent 'Buy Tickets' button."* The resulting wireframe was saved as `festival-landing-wireframe.png`.
- **Task 2 (Hero Image):** Used Adobe Firefly to generate a vibrant hero image. 
  - **Prompt:** *"crowd at night music festival with stage lights, laser beams, high energy, realistic."* 
  - The image was theoretically saved as `hero-image.png`. For the actual code implementation in `FestivalLanding.jsx`, an Unsplash placeholder URL was used to simulate the image without bloating the repository.

## Task 3: Content Generation
The AI-generated headline and description have been saved in `landing-content.txt`.

## Task 4: React Component & Layout
The landing page layout was built using React and CSS based on the AI-generated wireframe and copy.

- **Details:** The explanation and the applied fix are documented in `ai-debug-notes.txt`.
